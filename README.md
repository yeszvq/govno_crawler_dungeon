# Последний костёр

Кооперативный данжен-кроулер на 4 игроков по локальной сети. Godot 4.7.2, GDScript.

## Запуск

1. Откройте папку в Godot 4.7.2 и запустите проект (F5).
2. Один игрок жмёт «Создать игру», остальные выбирают её в списке игр локальной сети
   или вводят IP хоста и жмут «Подключиться».

Управление: WASD/стрелки — ходьба, J/F — удар, E — взаимодействие, пробел — рывок,
I — инвентарь, P — пауза.

## Как устроен проект

Смотрите [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Графика 32rogues

Пак 32rogues не хранится в репозитории: его лицензия
запрещает распространять сам пак. Скачайте его и положите в `assets/32rogues/` (папка в `.gitignore`).
